# Mind Swarm

Mind-swarm is an experimental A-Life simulator using LLM AI to drive the 'Cyber' cognition. 
Each Cyber lives in a world world consisting of a Linux filesystem that if can move and interact with.

Multiple Cyber live in the same mind-swarm and can communicate.

Each Cyber is an independent process that runs a continous cognition loop with bio-feedback to help priotise and keep its life forward.

Cyber do not have a goal in the conventional sense, that are encouraged to explore and learn, so we provide them books and lessons.
